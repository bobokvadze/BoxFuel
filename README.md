# 🥊 BoxFuel

**BoxFuel** არის AI-ზე დაფუძნებული კვებისა და ვარჯიშის ასისტენტი, რომელიც სპეციალურად მორგებულია მოკრივეებისა და სპორტსმენების ფიზიკურ მიზნებზე (BMR-ზე დაფუძნებული კალორიები, მაკროები და წონის მართვა).

აპლიკაცია იყენებს **Gemini AI**-ს ვიზუალურ შესაძლებლობებს კვების ფოტო-სკანირებისთვის, ხოლო **Supabase**-ს — მონაცემთა ბაზისა და ავტორიზაციისთვის.

---

### ✨ ძირითადი ფუნქციონალი

* 🔐 **ავტორიზაცია:** უსაფრთხო რეგისტრაცია და შესვლა Supabase Auth-ით.
* 📊 **BMR & კალორიების კალკულაცია:** დღიური კალორიებისა და ცილების სამიზნე მაჩვენებლების გამოთვლა ასაკის, სიმაღლის, წონისა და სქესის გათვალისწინებით.
* 📸 **AI Food Scanner:** საკვების ფოტოს გადაღება/ატვირთვა და Gemini-ს მიერ კალორიებისა და მაკრონუტრიენტების ავტომატური შეფასება.
* 📈 **დღიური პროგრესი:** კალორიების, ცილებისა და წყლის მიღების აღრიცხვა real-time რეჟიმში.

---

### 🚀 ტექნოლოგიები

* **Framework:** Next.js (React)
* **Database & Auth:** Supabase
* **AI Engine:** Google Gemini API
* **Styling:** Tailwind CSS
* **Deployment:** Vercel
