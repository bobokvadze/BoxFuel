# 🥊 FormAI

**Forma** არის AI-ზე დაფუძნებული კვებისა და ვარჯიშის ასისტენტი, რომელიც სპეციალურად მორგებულია მოკრივეებისა და სპორტსმენების ფიზიკურ მიზნებზე (BMR-ზე დაფუძნებული კალორიები, მაკროები, ვარჯიშის დატვირთვა და წონის მართვა).

აპლიკაცია იყენებს **Gemini AI**-ს ვიზუალურ შესაძლებლობებს კვების ფოტო-სკანირებისთვის, ხოლო **Supabase**-ს — მონაცემთა ბაზისა და ავტორიზაციისთვის.

---

### ✨ ძირითადი ფუნქციონალი

* 🔐 **ავტორიზაცია:** უსაფრთხო რეგისტრაცია და შესვლა Supabase Auth-ით (Custom SMTP მხარდაჭერით).
* 📊 **BMR & კალორიების კალკულაცია:** დღიური კალორიების, ცილებისა და წყლის სამიზნე მაჩვენებლების გამოთვლა ასაკის, სიმაღლის, წონის, სქესისა და ყოველკვირეული ვარჯიშების ინტენსივობის მიხედვით.
* 📸 **AI Food Scanner:** საკვების ფოტოს გადაღება/ატვირთვა და Gemini-ს მიერ კალორიებისა და მაკრონუტრიენტების ავტომატური შეფასება.
* 📈 **დღიური პროგრესი:** კალორიების, ცილებისა და წყლის მიღების აღრიცხვა real-time რეჟიმში.
